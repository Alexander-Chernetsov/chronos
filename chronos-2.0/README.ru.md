# Chronos 2.2.29

[English](README.md) · Русский

Chronos остаётся локальным планировщиком без сервера и установки. Рабочие
исходники разделены на несколько файлов. Открывайте [`chronos.html`](chronos.html)
или выпускной standalone. У номера приложения и версии формата данных `__schema__: 1`
отдельная нумерация.

## Пользовательская памятка

**Задача.** Нажмите `+`, введите название и завершите ввод Enter. В правой части
карточки при наведении или фокусе появляются «Сделано», корзина и `⋯`.
На телефоне постоянно доступна `⋯`; первый пункт меню — «Сделано».
Робот перед названием обозначает последнюю правку текста агентом и включает
фильтр автора. Он не является частью названия. Комментарий открывается нажатием
на его первую строку или Shift+Enter при редактировании названия.

**Метки.** Напишите, например, `Позвонить @Ирина #проект !срочно`.
Кнопка «Типы меток» непосредственно слева от шестерёнки управляет знаками:
добавьте один знак через `+` или Enter, выберите цвет либо отключите тип корзиной.
Отключение сохраняет текст задач и цвет. Составные знаки не поддерживаются.
В каждом типе выбирается одно значение; типы, поиск и автор объединяются через И.
Выбор новой метки того же типа заменяет прежний. Крестик снимает фильтр.

**Данные.** Без файла задачи хранятся только в этом браузере. Индикатор рядом
с дискетой открывает подключение рабочего JSON. После подключения изменения
сохраняются в файл автоматически. Ctrl+S сохраняет файл или предлагает экспорт.
При одновременной внешней правке выберите сохраняемую версию в диалоге конфликта.
Не открывайте один рабочий файл одновременно в старой и новой версиях приложения.

**Очистка.** «Сохранить и очистить» сначала экспортирует копию.
«Очистить без сохранения» требует подтверждения и очищает задачи локального
снимка, включая Сделано и Корзину, сохраняя типы меток. Связанный JSON отключается;
пустой снимок в него не отправляется. Уже начатое сохранение прежних правок может
завершиться. Изменение данных или подключения во время подтверждения отменяет очистку.

**Сделано и Корзина.** Задачи хранятся семь дней, затем удаляются автоматически.
Очистка Сделано переносит задачи в Корзину. Удаление из Корзины навсегда требует
подтверждения. До этого задачу можно восстановить.
Метки в Сделано и Корзине показываются теми же плашками и цветами, что на карточке.
Здесь они служат для чтения и не включают фильтры.

**Ошибки.** Если локальный снимок не прошёл проверку, приложение пытается
сохранить recovery-копию. До успешного сохранения исходного снимка его замена
приостановлена. Неподдерживаемая версия JSON не преобразуется молча.
Папки тем и языков можно подключить заново в настройках, если доступ утрачен.

| Клавиши | Действие |
|---|---|
| N | Новая задача на сегодня |
| Shift+N | Список задач на сегодня |
| I | Новая задача во Входящих |
| C | Новая задача в Контроле |
| Ctrl+F | Поиск |
| T | Сегодня |
| [ / ] | Предыдущий / следующий диапазон |
| Shift+T | Перенести просроченные задачи после подтверждения |
| Enter | Сохранить название; при открытых подсказках вставить выбранную |
| Shift+Enter | Открыть комментарий из названия |
| Ctrl+Enter | Сохранить текущий редактор |
| Ctrl+S | Сохранить файл или экспортировать |
| Esc | Закрыть верхний слой / завершить редактирование |
| ? | Открыть короткую памятку |

Буквенные команды не срабатывают в полях ввода и модальных окнах.
На Mac вместо Ctrl используется Cmd. Встроенная памятка доступна офлайн,
даже если этот README отсутствует рядом с перенесённым standalone.

## Устройство приложения

Сохраняйте каталоги рядом с исходным HTML:

```text
chronos-2.0/
  chronos.html
  scripts/
    chronos.core.js
    chronos.storage.js
    chronos.customization.js
    chronos.board.js
    chronos.month.js
    chronos.tasks.js
    chronos.dialogs.js
    chronos.js
  styles/
    chronos.base.css
    chronos.board.css
    chronos.month.css
    chronos.dialogs.css
    chronos.views.css
    chronos.help.css
  themes/
    chronos.theme.css
    *.css
  locales/
    chronos.locale.js
    russian.locale.js
    *.locale.js
```

Восемь обычных скриптов подключаются в фиксированном порядке без ES-модулей и
сборщика. `chronos.core.js` отвечает за состояние и модель данных,
`chronos.storage.js` — за localStorage, подключённый JSON и каталоги,
`chronos.customization.js` — за языки и оформление, `chronos.board.js` — за
доску, колонки и фильтры, `chronos.month.js` — за месячный вид,
`chronos.tasks.js` — за карточки и операции с
задачами, `chronos.dialogs.js` — за окна и шпаргалку клавиш, а `chronos.js` — за
события и запуск. Стили разделены на основу и шапку, доску, месяц,
диалоги, варианты представления и компактную памятку в шести файлах
`styles/chronos.*.css`.
Палитра, шрифты, радиусы и эффекты задаются токенами темы, которые стили
используют внутри конкретных селекторов.
Тема `themes/focus.css` предлагает нейтральные поверхности без декоративных
теней, градиентов и размытия в светлой и тёмной схемах. Цвета меток, статусов
и действий сохраняют своё значение. Она подключается через папку тем,
как и «Графит и мох» и остальные дополнительные темы.

## Standalone-выпуск

Для передачи Chronos одним файлом выполните из корня репозитория:

```powershell
node tools/build-standalone.mjs
```

Скрипт без зависимостей создаёт
`output/chronos-2.0-standalone.html`: встраивает обязательные стили, восемь
скриптов, каноническую тему и каноническую локаль в порядке из `chronos.html`.
Задачи, резервные копии и дополнительные каталоги тем и локалей в выпуск не
попадают. Их можно подключать к standalone теми же кнопками папок.

Файл в `output/` является воспроизводимым выпускным артефактом, игнорируется
Git и не редактируется вручную. Единственный источник истины — файлы в
`chronos-2.0/`.

Режим `node tools/build-standalone.mjs --demo` создаёт `output/site/index.html`
из тех же исходников. Он заранее подключает все 23 темы и четыре локали,
выбирает «Графит и мох» и схему системы только при первом входе.
Примеры показывают следующие семь дней от сегодня, восемь активных задач
и по одной вчерашней задаче в Сделано и Корзине. Последующие
изменения сохраняются в отдельном пространстве `chronos-planner-demo-v2`, включая
recovery, настройки и IndexedDB. Существующий пустой или повреждённый снимок
примерами не заменяется. Смена языка переводит интерфейс, но не текст задач.
Сброс демо требует подтверждения и не действует при
подключённом JSON. Подключённая папка может заменить встроенный пакет по его
смысловому идентификатору или имени файла; при отказе доступа встроенный каталог остаётся.

Рядом с навигацией по датам переключаются два базовых вида: Доска и месяц. Кнопка показывает вид,
в который она переведёт: календарь на Доске и три колонки в Месяце. Действия карточки
появляются справа при наведении и фокусе клавиатуры. На сенсорном экране
кнопка `⋯` видна постоянно. Наведение не меняет высоту карточки. Месяц показывает семь
дней в строке, включая задачи соседних месяцев; внутри каждого дня список
прокручивается отдельно. Соседние месяцы приглушены, а сегодня отмечено
усиленным контуром и общей для всех видов заливкой шапки. На Доске `+` появляется
в свободной области под задачами, в
развёрнутой колонке — в первой свободной ячейке сетки, а в месяце — в пустом
доступном дне; прошлые даты остаются доступными для просмотра, но не принимают
новые и перенесённые
задачи. Клик по заголовку дня открывает обычную развёрнутую
колонку. Клик по заголовку развёрнутой колонки возвращает в выбранный базовый
вид; в Месяце открывается месяц текущего развёрнутого дня, даже если переход к
нему выполнен кнопкой «Сегодня», стрелками или календарём. `Esc` делает то же
только тогда, когда не открыто меню или редактор задачи.
На Доске исходный диапазон сохраняется, пока текущий развёрнутый день входит в
него. Если выбранная дата оказалась за его пределами, она занимает числовую
позицию «Сегодня».

Временные элементы центральной части идут от проблем к настройке диапазона:
просроченные задачи, активные задачи до видимого диапазона, количество дней,
сам диапазон и позиция сегодняшнего дня. На узком экране тот же набор занимает
две строки без дублирования действий.

В правой части шапки отдельный нейтральный счётчик показывает общее число
активных задач перед кнопками «Сделано» и «Корзина».

Маркеры пользовательских типов меток можно написать отдельным словом в любом
месте названия: например, `Обсудить плитку @Ирина #стройка !срочно`.
Тип меток — включённый знак. Кнопка со слоями слева от шестерёнки открывает список
«знак — цвет — корзина». Новый знак включается кнопкой `+` или Enter.
У каждого типа меток один цвет для всех его значений. Форма плашек одинакова.
Плашки показывают только значение, а знак остаётся в исходном тексте.
Эмодзи входят в имя. Приложение не назначает словам особый смысл.

Кнопки включённых типов меток находятся после поиска. В каждом фильтре
выбирается одно значение. Следующий выбор заменяет предыдущий, повторный
клик снимает выбор. Между типами меток, поиском и фильтром автора действует AND.
В задаче допускается несколько маркеров одного типа меток.
Списки собираются из активных задач, включая Контроль и просроченные дни.
Архив и Корзина не участвуют в поиске и списках фильтров.
Кнопка показывает только знак; точка обозначает выбранный фильтр. Полное значение
видно в подсказке и строке списка. Верхняя подпись рядом с крестиком снятия фильтра
может сокращаться многоточием.
Меню фильтров открываются под своими кнопками и сдвигаются внутрь окна у его края.
При переносе группы кнопок меню начинается ниже всей шапки. Остальные меню шапки
открываются у правого края экрана ниже шапки. Длинные списки
прокручиваются; меню не обрезается контейнерами панели управления.
Пустая кнопка недоступна. Выбранные фильтры типов меток не сохраняются в JSON.

При вводе включённого знака появляются подсказки существующих значений.
В карточке, редакторе задачи и вводе списка их ширина определяется самым длинным
вариантом. Длинные значения переносятся в пределах окна, длинный список прокручивается.
Стрелки выбирают вариант, Enter вставляет его, Esc закрывает список.
Без выбранной подсказки Enter сохраняет название. Новое имя можно написать
свободно. Одиночное и массовое создание наследует выбранные фильтры без дублей.

Кнопка корзины отключает плашки, подсказки и фильтр типа меток.
Исходный текст и цвет остаются. При возврате знака плашки восстанавливаются.
Метка робота обозначает последнюю правку агентом; клик включает фильтр автора.
Она не назначает владельца задачи. Любая правка текста человеком снимает метку.

Крестик в конце группы фильтров сбрасывает поиск и все активные фильтры сразу.

Лупа или Ctrl/Cmd+F открывает отдельное поле поиска под кнопкой, не сдвигая шапку.
Повторное нажатие, Escape или клик снаружи закрывает поле, сохраняя запрос и
фильтрацию. Активная лупа показывает, что поиск действует; запрос виден в подсказке.
Снять поиск вместе с фильтрами можно общим крестиком.

Окно «Сделано/Корзина» сохраняет размер при переключении вкладок и пустых списках.
Длинные списки прокручиваются внутри. Высота — до 640px и не более 88% окна.
Панель действий карточки имеет сплошной фон и форму активной темы, как кнопки и метки.

В настройках указана версия приложения и SHA исходного коммита standalone.
`+modified` возле SHA означает сборку с изменёнными исходниками.
При открытии исходного `chronos.html` SHA не показывается.
Правила номера `X.Y.Z` и выпускной сборки описаны в [основном README](../README.ru.md).

Кнопка памятки и клавиша `?` открывают короткую офлайн-памятку справа: до половины ширины окна
на компьютере и на доступную ширину телефона, от шапки до нижнего отступа 8px.
Оглавления нет; остаются правила хранения, конфликты, recovery, семь дней хранения
и полный набор горячих клавиш. Escape закрывает памятку и возвращает фокус.


Редактор задачи сохраняет название и комментарий вместе. Очистка действует
только на комментарий, пустое название сохранить нельзя. Закрытие несохранённых
изменений и перенос задачи в корзину подтверждаются внутри этого же окна. Во
вкладке «Сделано» перенос отдельной задачи в корзину использует тот же встроенный
паттерн; слово «Удалить» относится только к безвозвратному удалению из корзины.

## Тема по умолчанию

Чтобы назначить другую тему по умолчанию, скопируйте подходящий файл из
[`themes/`](themes/) поверх [`themes/chronos.theme.css`](themes/chronos.theme.css).
Править HTML или JavaScript не нужно.

Тема сообщает Chronos стабильный идентификатор, название и монохромную иконку
через CSS-переменные:

```css
:root {
  --chronos-theme-id: "notebook";
  --chronos-theme-name: "Блокнот";
  --chronos-theme-icon-path: "M4 3H20V21H4ZM8 3V21";
  --task-text-size: 0.8rem;
  --marker-l: 47%;
  --marker-c: 0.13;
}
:root[data-theme="dark"] {
  --marker-l: 80%;
  --marker-c: 0.12;
}
```

`--chronos-theme-icon-path` содержит только команды SVG-path для поля
`viewBox="0 0 24 24"`. Chronos проверяет команды и ненулевую геометрию, затем создаёт SVG через DOM; полный
SVG или HTML из темы не выполняется. Поэтому тема вместе с собственной иконкой
целиком живёт в одном CSS-файле и не требует правки JavaScript.
`--marker-l` и `--marker-c` задают светлоту и насыщенность плашек в обеих схемах.
Оттенок хранится у типа меток в данных. Фон и контур вычисляются автоматически.
`--task-text-size` задаёт один размер названия задачи на Доске, в фильтрах
маркеров, Архиве и Корзине. Месяц намеренно сохраняет отдельный компактный
размер. Каждая автономная тема объявляет токен, а темы с особым шрифтом могут
скорректировать его под свои метрики.

Шестерёнка открывает единое меню настроек. В первой строке
выбирается язык, подключается папка локалей и справа закрывается меню; во второй
переключается светлая или тёмная схема, выбирается тема и подключается папка
дополнительных `.css`-файлов. Типы меток управляются отдельной кнопкой слева от шестерёнки.
Выбранная пользователем дополнительная тема имеет приоритет над корневой. Чтобы
увидеть новый дефолт, выберите в меню его значок. `chronos.theme.css` —
единственный канонический файл темы по умолчанию. При чтении подключённой папки
Chronos узнаёт его по идентификатору и не создаёт второй пункт меню.
Добавление или удаление дополнительной темы сводится к добавлению или удалению
её CSS-файла.

## Язык по умолчанию

Канонический язык Chronos — English (`en-GB`). Русский интерфейс находится в
[`locales/russian.locale.js`](locales/russian.locale.js) и подключается вместе
с каталогом дополнительных локалей.

Чтобы назначить другой язык по умолчанию, скопируйте подходящий файл из
[`locales/`](locales/) поверх
[`locales/chronos.locale.js`](locales/chronos.locale.js).

Локаль по умолчанию и дополнительные локали используют один формат. Ниже
показан только фрагмент структуры, а не готовый сокращённый языковой файл:

```js
window.CHRONOS_LOCALE_PACK = {
  "chronosLocale": 1,
  "locale": "en-GB",
  "name": "English",
  "shortLabel": "EN",
  "messages": {
    "help.guide.title": "Quick reference"
  }
};
```

Объект должен быть строгим JSON внутри фиксированного присваивания. Файлы из
подключённой папки читаются как текст и разбираются как данные — Chronos не
выполняет их код. Выбранная пользователем дополнительная локаль имеет приоритет
над локалью по умолчанию. Все локали содержат полный и одинаковый набор
смысловых ключей; числовые ключи старых прототипов не поддерживаются. Новый
файл проще начинать с полной копии существующей локали и переводить только
значения.
`chronos.locale.js` — единственный канонический файл локали по умолчанию. При
чтении подключённой папки Chronos узнаёт его по языковому коду и не создаёт
второй пункт меню. Имя, код кнопки, формат дат и полный словарь находятся в
самом `.locale.js`; добавление или удаление локали не требует правки HTML,
JavaScript или отдельного реестра.

## Отказоустойчивость

- без корректного `themes/chronos.theme.css` Chronos показывает нейтральное
  сообщение об ошибке темы вместо скрытого оформления;
- без корректного `locales/chronos.locale.js` Chronos показывает нейтральное
  сообщение об ошибке локали; русских строк в HTML и JavaScript нет;
- ошибка дополнительной темы или локали пропускает только этот файл;
- задачи используют ключ `chronos-planner-v2`. Схема задач строгая: скрытые поля
  старых прототипов `done` и `originalKey` не принимаются. Подключайте JSON
  текущего формата; при ошибке браузер пытается сохранить исходный localStorage в
  recovery-копию и не подменяет им валидный файл;
- пустые календарные даты удаляются при обычном сохранении. Пустые служебные
  разделы Входящих, Контроля, архива и корзины сохраняются как часть схемы.

Автоматически перечислять произвольные соседние файлы браузер при `file:///` не
может. Поэтому слоты по умолчанию имеют фиксированные имена, а каталоги тем и
локалей подключаются пользователем через File System Access API в Chrome или
Edge.

Локали проверяются по точному набору ключей и параметров сообщений. Текущий набор
содержит 257 ключей; 34 неиспользуемых ключа прежнего интерфейса и полного руководства
удалены из всех четырёх локалей. Старые пакеты с лишними ключами отклоняются.
При обновлении замените папку поставляемых локалей и обновите собственные пакеты
по текущему `chronos.locale.js`. Перезагрузите обновлённый standalone, чтобы код
и подключаемые локали имели один точный набор ключей.

## Формат данных

Рабочий JSON содержит `__schema__: 1`, массив включённых знаков `__dimensions__`
и объект оттенков `__dimensionColors__`. Цвет отключённого типа меток сохраняется.
Задачи содержат ID, название, комментарий, метку автора и служебные даты.
ID новых задач создаёт код: браузер использует UUID, CLI — повторяемый ID с
проверкой коллизий, чтобы dry-run совпадал с применением. Агент не передаёт `id`
в операции `create`; для остальных операций берёт существующий ID из `list`.
Числовые и строковые ID допустимы, существующие значения не меняются.
Поля `starred`, `urgent`, `inProgress` и режим `cardStyle` больше не принимаются.
Агент меняет маркеры через `edit`, сохраняя настройки типов меток.

Приложение принимает только текущую схему и отклоняет неподдерживаемый формат
с понятным сообщением. Старые JSON автоматически не преобразуются. При ошибке
локального снимка Chronos пытается сохранить его recovery-копию; она сохраняет
исходные данные без преобразования. До успешного сохранения копии перезапись
снимка и импорт приостановлены.
