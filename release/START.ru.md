# Запуск Chronos

[English](START.md) · Русский

1. Распакуйте весь ZIP в свою папку.
2. Откройте `chronos.html` в актуальном Chrome, Edge или Brave. Установка и Node не нужны.
3. Добавляйте задачи через `+`. Клавиша `?` открывает офлайн-памятку о клавишах и данных.
4. В настройках выберите папки `themes/` и `locales/` из архива: появятся все
   23 темы и четыре языка. Разрешите доступ, когда браузер запросит его.

Без этих папок в HTML всё равно есть стандартная тема и English.
Выбранные тема и язык запоминаются в этом браузере.

Изначально задачи хранятся в localStorage браузера. Дискета экспортирует JSON;
подключите его индикатором рядом для автоматической записи. Регулярно экспортируйте копии.
Сделано и Корзина автоматически удаляют задачи через семь дней.

Для файлов и папок нужен поддерживаемый браузер. Запасного файлового импорта/экспорта
при отсутствии File System Access API нет. Старые форматы JSON отклоняются,
а не преобразуются автоматически.

[Полное руководство и исходники](https://github.com/Alexander-Chernetsov/chronos)
· [Онлайн-демо](https://alexander-chernetsov.github.io/chronos/)

Для необязательного CLI агента нужны исходный репозиторий и Node; в этом ZIP его нет.

и внутри самостоятельного HTML.
